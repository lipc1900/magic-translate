# Acceptance — whole-page-translate

每条**具体、可观察、可验证**，由独立只读 Verifier 逐条判定 passed/failed/blocked。

## 功能

1. 在 GitHub 任意英文 README 页点击图标后，正文整页替换为简体中文，翻译前后 `code/pre/a/img/table/li` 元素数量完全一致，所有 `href`/`src` 原样、控制台 0 error。
2. 代码块、内联代码、命令不被翻译。
3. 再点一次图标（或右键「还原原文」）后，页面完整恢复英文原文。
4. 未配置 API Key 时点击图标，出现明确提示引导去设置页填 Key（非静默失败）。
5. 二次访问同一页面（或内容相同的镜像页）走缓存直接渲染译文，不重复请求 DeepSeek。

## 性能

6. 冷启动打开 5000 字符英文页面，点击翻译后**首段译文 ≤2s**（Performance 计时验证）。
7. 整页 95% 文本块完成 ≤20s（云端 P95）。
8. 缓存命中时整页渲染 ≤50ms。
9. 翻译期间主线程单次长任务 ≤50ms，页面持续可滚动、可取消。

## 稳定性

10. 单块翻译失败自动重试 1 次；仍失败标记该段并在界面汇总，不阻塞其他块。
11. 翻译中点「取消」≤300ms 停止新请求，已渲染内容保留。
12. 连续触发动态内容更新 + 滚动到底再回顶，无文本节点被二次替换；相同句子二次翻译零新增请求。
